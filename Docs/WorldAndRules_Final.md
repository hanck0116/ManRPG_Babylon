# ManRPG Babylon World And Rules

이 문서는 구현 기준 요약본이다. 원본 최종 통합 지시서는 사용자 제공 파일 `ManRPG_Babylon_Codex_세계관_전체설정_최종통합본.txt`를 기준으로 한다.

## 핵심 루프

1. 타이틀 화면
2. 캐릭터 생성
3. 캐릭터 시트 확인
4. 층 전투
5. 적 처치와 성장 지급
6. 3D 심상세계 진입
7. 보상 뽑기권, 저장고, 만트라 석상, 상점, 연습실, 게이트 상호작용
8. 다음 층 진입

## 삭제된 구버전 규칙

- 전승
- 포션
- 포션 상점
- 적 직접 아이템 드랍
- 직접 스탯 보상
- luck 키
- 모든 스탯 10 시작
- 마법 버튼 즉시 발동

## 구현 기준

- 전투는 실시간 3D 액션이다.
- 다이스는 마법서 습득 같은 비전투 판정에만 사용한다.
- 모든 스킬은 만트라를 전제로 한다.
- 마법은 준비 후 발동한다.
- 심상세계 기능은 UI 자동 노출이 아니라 3D 오브젝트 상호작용으로 열린다.
